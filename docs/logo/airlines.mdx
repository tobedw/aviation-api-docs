---
title: Airline Logos
description: Retrieve airline logos by ICAO or IATA code with optional variant selection.
---

## Endpoints

```
GET /airlines/icao/{ICAO}
GET /airlines/iata/{IATA}
```

When using an IATA code, the API automatically resolves it to an ICAO code via a database lookup to find the best matching asset.

## Parameters

| Parameter | Description | Example |
|---|---|---|
| `key` | Your API key | `?key=YOUR_API_KEY` |
| `variant` | Logo variant (see below) | `?variant=tail` |
| `format` | `svg` or `png` | `?format=png` |
| `size` | PNG output size in pixels | `?size=400` |
| `loop` | Only with `variant=icon-animated`. `false` or `0` plays the animation once | `?loop=false` |
| `force` | Bypass cache (`true`) | `?force=true` |

## Variants

| Variant | Description |
|---|---|
| *(default)* | Icon logo, falls back to logo with background |
| `icon-transparent` | Icon on transparent background |
| `logo` | Logo with colored background |
| `logo-transparent` | Logo on transparent background |
| `logo-bg-white` | Logo on white background |
| `logo-white` | White version of the logo |
| `tail` | Tail livery |
| `tail-3D` | 3D tail livery, falls back to flat tail |
| `icon-animated` | Animated SVG icon (Pro and Enterprise only, see [Animated icons](#animated-icons)) |

## Animated icons

`variant=icon-animated` returns the airline icon as an animated SVG. It works with ICAO, IATA and AWB prefix identifiers.

- **Plans:** Pro and Enterprise only. Other plans receive `403`. The request is not counted against your quota.
- **Format:** Always `image/svg+xml`. `format` and `size` are ignored, because rasterizing to PNG would remove the animation.
- **Fallback:** If no animation exists for an airline, the static icon (default `icon` variant) is returned. Check the `X-Asset` response header to see which file was served.
- **Embedding:** Use `<img src="…">` or `<object>`. Some environments show only the first frame, e.g. many email clients and some native image views.

### `loop`

Only valid with `variant=icon-animated`.

| Value | Result |
|---|---|
| omitted / `true` | Looping animation (default) |
| `false` or `0` | Plays once |

### Error (plan too low)

```
HTTP 403
```

```json
{ "error": "Animated icons require the Pro plan or higher.", "upgrade": "https://polar.sh/yourorg" }
```

## Response

Successful responses return the image directly with appropriate content-type headers:

```
Content-Type: image/svg+xml          (SVG)
Content-Type: image/png              (PNG)
Cache-Control: public, max-age=31536000, immutable
X-Cache: MISS | KV
X-Resolved-Via: direct | iata-db
X-Asset: DLH_icon
X-Source: R2 | TwicPics | fallback
```

### Observability headers

| Header | Description |
|---|---|
| `X-Cache` | `MISS` = fresh lookup, `KV` = served from cache |
| `X-Resolved-Via` | `direct` = ICAO used as-is, `iata-db` = IATA resolved to ICAO |
| `X-Asset` | Filename of the asset that was served |
| `X-Source` | Asset origin: `R2`, `TwicPics`, or `fallback` |
| `X-Fallback` | `true` if a generated placeholder was returned |
